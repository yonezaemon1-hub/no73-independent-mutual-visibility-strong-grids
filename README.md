# Exact Independent Mutual-Visibility Chromatic Numbers of Strong Grid Graphs

Ryutaro Yonezu — Independent Researcher  
Research No.73 · Version 1.0 · 18 November 2026 · Preprint, not peer reviewed

For all integers `t >= r >= 3`, the paper gives the exact independent
mutual-visibility chromatic number of the strong grid `P_t ⊠ P_r` as
`max(4, ceil(r/2))`. The lower bound and the full-width even-palette pattern
are due to Brešar, Peterin, Samadi and Yero (2026), Theorems 27–28. The
candidate contribution is an odd-palette construction and a common geodesic
argument covering the remaining widths and justified column restriction.
